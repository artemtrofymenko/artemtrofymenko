## Work you can check

**[ReadyCSV](https://www.readycsv.com)** · CSV preflight for HubSpot imports<br>
Inspect, repair, map and export CSV files before they reach the CRM. File processing stays in the browser. The October release fixed malformed quotes, stale fixes overwriting manual edits, special column names and delimiter detection. It shipped after 192 unit and 64 end-to-end tests and was checked again on the live site.

**[SkuSum](https://skusum.com)** · Amazon profit by SKU, and a journal that balances<br>
Joins Amazon's orders, settlement and advertising reports with the seller's own cost file into profit by SKU and a QuickBooks or Xero journal, in the browser. Every run checks that debits equal credits and grades data quality separately, so "the books tie out" never hides "the margins are not trustworthy yet". High-severity exceptions block the export. There is no model in the data path: an unknown fee type is flagged for review, not guessed.

## How I work

- Start from the operational decision, then pick the tool.
- Write down what "correct" means before anything is built.
- Check the output where it lands: the exported file, the live page, the record the next system reads.
- Every handoff says what was verified and what was not.
