**[LeakRelay](https://www.leakrelay.com/)**: missed-call lead response for water-damage restoration companies (Twilio + Claude).

Live landing and demo; limited pilot by request; source is private. | [live](https://www.leakrelay.com/)

## How I work

- Start from the operational decision, not the tool.
- Privacy-first by default: no backend, auth, or AI runtime until there is a real reason for one.
- AI-assisted development with explicit smoke tests.
- Bounded, inspectable, recoverable automation: ship small, then scale.
